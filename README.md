# Student Performance Analysis

A Streamlit web app that analyzes student marks using Python and Pandas.

## Features
- Total marks, average, highest and lowest scorer
- Grade calculation (A+, A, B, C, D)
- Pass/fail result and pass percentage
- Subject-wise average and subject toppers
- Upload your own CSV file for analysis
- Student search by name
- Pass/fail chart
- Charts and student marks table

## Technologies Used
- Python
- Pandas
- Streamlit
